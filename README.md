# johnnyhng.github.io

GitHub Pages source for the main project index and the ezTalk sub-site.

## Published URLs

- Main page: `https://johnnyhng.github.io/`
- ezTalk: `https://johnnyhng.github.io/eztalk/`
- ezTalk Privacy Policy: `https://johnnyhng.github.io/eztalk/privacy.html`
- ezTalk Terms of Service: `https://johnnyhng.github.io/eztalk/terms.html`

## Deployment

Create a public repository named exactly `johnnyhng.github.io` and upload the **contents** of this directory to its root. In repository Settings → Pages, select “Deploy from a branch,” branch `main`, folder `/(root)`.

The `eztalk/` directory is the actual sub-site path. Do not add another nested `eztalk/` directory.
