## Deployment

Create a public repository named exactly `johnnyhng.github.io` and upload the **contents** of this directory to its root. In repository Settings → Pages, select “Deploy from a branch,” branch `main`, folder `/(root)`.

The `eztalk/` directory is the public product site used by OAuth branding. The `work/` directory is deliberately separate and contains resume-appendix case studies. Internal planning documents are not published with the case study.
